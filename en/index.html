7 splitting rules for everyday business

Per account, by region, by date, by range… pick a rule and let ForceSplit do the rest.

By field value (per account)

Rows sharing the same field value go into the same file — one file per customer, unit, or account, nothing mixed.

By administrative region

Based on ID numbers, taxpayer identification numbers, or region codes: split by province / city / county, into a flat or nested folder tree.

By date

Group records by year, quarter, month, week, or day — periodic data files itself.

By numeric range

Segment numeric columns such as amounts and quantities into ranges.

By prefix / keyword

Group rows by text prefix or contained keywords — handy for codes and numbered records.

By row count

Cut a big sheet into fixed-size files for easy batching and distribution.

By phone number region

Detect the province / city and carrier behind each phone number, and file records by region.

Built to split it right

More than cutting files: preview before the split, reconcile after it, and slim down the output.

Preview before splitting

Preview the split and preprocessing, adjust the rules freely, and only write files when you're satisfied.

Row-count conservation

Total rows are verified before and after the split — nothing lost, nothing duplicated.

Output field filtering

Every output file keeps only the fields you need — nothing extra goes out.

Reusable split plans

Save frequently used rules as plans and apply them to the next file in one click.

200,000 rows per sheet

Up to 200,000 rows per worksheet; overflow continues automatically on a new sheet.
